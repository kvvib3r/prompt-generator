# НейроПомощник — Конструктор промптов для нейросетей

Простой и удобный веб-инструмент, который помогает правильно формулировать запросы (промпты) для ChatGPT, Midjourney, Шедеврума и других ИИ. 

## 🚀 Ссылка на проект
Попробовать сервис в действии можно здесь: https://powerofsex.github.io/prompt-generator/

## 🛠 Как это работает
Сайт автоматизирует правила Prompt Engineering:
1. Вы выбираете **роль** для нейросети (копирайтер, программист и т.д.).
2. Описываете **задачу** своими словами.
3. Указываете желаемый **стиль** ответа.
4. Нажимаете кнопку и получаете готовый структурированный запрос, готовый к копированию.

## 💻 Технологический стек
Проект написан без использования тяжелых фреймворков (Vanilla веб):
* HTML5
* CSS3 (Адаптивный интерфейс, темная тема)
* JavaScript (Логика сборки строки и копирования в буфер обмена)
